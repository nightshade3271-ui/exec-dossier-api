Developer Instructions

Simple, Scalable REST Integration

Connect ExecDossier to your outbound sales automations, CRM enrichment workflows, or cold email tools in minutes.

POST /v1/dossier/analyze
Returns: application/json

The full psychographic dossier endpoint. Analyzes role taxonomy, quarterly headaches, attention thresholds, buzzword filters, 3 tailored cold hooks, and objection strategies.

curl -X POST "https://exec-dossier-api.vercel.app/v1/dossier/analyze" \ -H "Content-Type: application/json" \ -d '{ "name": "Sarah Chen", "title": "VP of Engineering", "company": "FintechScale Systems", "industry": "Financial Technology SaaS" }'
const response = await fetch('https://exec-dossier-api.vercel.app/v1/dossier/analyze', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Sarah Chen', title: 'VP of Engineering', company: 'FintechScale Systems', industry: 'Financial Technology SaaS' }) }); const { data } = await response.json(); console.log('Archetype:', data.executive_summary.archetype); console.log('Top Icebreaker:', data.cold_outreach_intelligence.icebreakers[0].body_text);
import requests url = "https://exec-dossier-api.vercel.app/v1/dossier/analyze" payload = { "name": "Sarah Chen", "title": "VP of Engineering", "company": "FintechScale Systems", "industry": "Financial Technology SaaS" } res = requests.post(url, json=payload).json() icebreakers = res["data"]["cold_outreach_intelligence"]["icebreakers"] for hook in icebreakers: print(f"[{hook['angle']}]: {hook['body_text']}\n")
